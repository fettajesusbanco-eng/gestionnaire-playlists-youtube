Créer, renommer, modifier la description ou supprimer une playlist

La suppression d'une playlist est définitive, mais les vidéos restent sur YouTube. Une confirmation renforcée sera demandée.

Créer et organiser les sections de l'accueil

Une section affiche une ou plusieurs playlists : elle n'est pas un dossier YouTube. Les playlists privées ne peuvent pas y figurer. Les autres types de sections restent inchangés.

Écrire une description et/ou un commentaire

La publication d'un commentaire n'est pas un remplacement : évite les doublons. Un commentaire déjà publié ne sera jamais reposté automatiquement pendant la même session.

Importer ton Excel de classement ou tes textes rédigés avec ChatGPT

Colonnes acceptées : Titre de la chanson, Playlist de création correspondante, Description YouTube, Commentaire, et idéalement Video ID. Les correspondances de titres ambiguës sont ignorées. Aucune playlist absente n'est créée automatiquement.
